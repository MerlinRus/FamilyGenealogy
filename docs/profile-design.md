# Человек, факт, источник

Задача: Марк должен сразу увидеть свои сведения и родителей, а из «Киров» открыть именно основание этой записи. Чтение и редактирование одинаково доступны; происхождение сведений не подменяет уверенность в родстве.

## Выбор композиции

Вариант с постоянно раскрытыми основаниями и колонкой документов отклонён: каждый факт повторяется до четырёх раз, боковая колонка отвлекает от биографии.

Выбран семейный профиль с отдельными адресуемыми страницами фактов. Ключевая визуальная деталь — близкие рядом с биографией; вместо одинаковых карточек используется одна спокойная поверхность с двумя разными зонами.

```text
Имя человека                                   Редактировать
Роль в семье · личная уверенность
О человеке | Источники (2) | Прежние сведения
Основные сведения                      Близкие
Год рождения                           Родители
2003          Откуда известно          Игорь Владимирович
Откуда родом                           Мария Валерьевна
Киров…        Откуда известно          Добавить связь
Добавить факт
```

Источник открывается с сохранённым контекстом человека/факта. Вкладки «Сведения», «Оригинал», «Файлы и реквизиты» меняют содержимое и адрес, работают с браузерным «Назад». Исходные цитаты, файлы и оговорки не удаляются. Описание источника не подменяет относящийся к человеку факт.

## Токены

- Фон #F5F7FB; поверхность #FFFFFF; основной текст #202B43; пояснения #5D6880; действие #3155A4; граница #DBE3F0.
- Один шрифт: Segoe UI Variable Text / Segoe UI / системный sans-serif, кириллица без загрузки извне. Имя 40–48 px, значения 24–28, разделы 24, основной текст 18–20, подписи 16–18. Вес и размер обозначают роль; объяснение никогда не крупнее самого факта.
- Шаг отступов 8 px, внутреннее поле поверхности 32–40 px; основная ширина до 1440 px, текст до 72 знаков в строке. Всё выровнено слева.
- Синие подчёркнутые ссылки обозначают переход; кнопки имеют видимую границу/заливку. Имена близких — единая кликабельная строка с подписью «Открыть». Никаких невидимых стрелок и технических идентификаторов на первом экране.
- Сравнение с шаблонной карточкой: убраны метрики, россыпь бейджей, декоративные рубрики и четыре конкурирующие кнопки в шапке. Добавление факта находится у фактов, добавление связи — у близких. На телефоне близкие следуют сразу за фактами.

Проверка: исходный путь P001 → факт о Кирове → относящаяся цитата → оригинал → назад; родитель; редактор; источник без контекста; кандидат; 2560×1440 и 390×844.
