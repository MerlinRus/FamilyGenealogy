# Семейный атлас

Предмет: рабочая генеалогия семьи, где семейные рассказы, архивные записи и кандидаты существуют рядом с явными основаниями. Главная задача — увидеть человека в контексте и открыть источник, не приняв совпадение за установленное родство.

Палитра: ледяной фон #f2f6fa, белая бумага #ffffff, чернила #18344b, отцовская линия #4264c7, материнская #237f75, кандидаты #a57524. Цвет обозначает ветвь или тип записи, не служит украшением.

Шрифты: системный Segoe UI для кириллицы и плотных карточек; Georgia для названия семейного атласа. Крупные фамилии — ориентиры на схеме. Никаких внешних шрифтов и аналитики.

Композиция: спокойная навигация слева, большой рабочий холст справа, карточка выбранного человека поверх правого края. Люди и источники имеют отдельные полноразмерные представления. На телефоне навигация становится нижней панелью, досье — полноэкранным.

```text
Навигация | Заголовок + поиск
          | Ветви / кандидаты / легенда
          | Древо: предки сверху, младшие поколения снизу
          |                               | Досье человека
          | Масштаб / центрирование         | Факты → источники
```

Проверка плана: вместо декоративной обложки сразу показываем рабочую схему. Карточки людей являются узлами графа, источники — каталогом документов; одинаковая карточная сетка не используется для всех сущностей. Кандидаты связаны с человеком гипотезой тождества, а не вымышленными родительскими линиями. Семейные родства показываются пунктиром и сопровождаются оговоркой о происхождении сведений.

Сайт закрывается паролем целиком. Семейный набор данных и файлы источников никогда не коммитятся в репозиторий кода.
